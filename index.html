Open Projects

Math Mine

Math Mine is a Python-based educational content engine that generates curriculum-aligned mathematics worksheets and problem sets on demand. The platform combines LLM-driven content creation with a modular backend architecture designed for scalability, maintainability, and extensibility.

Status: Active Project

Spin Master

Spin Master is a Python-based slot machine simulation and mathematical analysis application designed to model, evaluate, and validate the behavior of configurable five-reel slot games. The system combines probability theory, combinatorics, statistical analysis, and Monte Carlo simulation to analyze game performance and payout behavior.

Status: Active Project

Image Alchemist

Image Alchemist is a modular image-processing project created to explore image enhancement and transformation workflows through clean, composable architecture. The project originated from an OCR challenge involving difficult-to-read image text and evolved into a framework emphasizing clarity, maintainability, and reusable processing pipelines.

Status: Active Project
